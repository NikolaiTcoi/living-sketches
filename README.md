# Living Sketches: Thirsty Sprout

A small animated p5.js scene made from hand-drawn objects, for Creative Coding Lab (Fall 2026).

The watering can follows your mouse. Click and hold to pour. Every drop that lands in the pot helps the seed grow, from sprout to bud to flower. If you stop watering, it slowly dries out.

- **R**: start over
- **D**: debug view

Open `index.html` through a local server (for example VS Code Live Server) to run it.
